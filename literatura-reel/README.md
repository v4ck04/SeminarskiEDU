# Reel: Kako pravilno izabrati literaturu za seminarski rad?

OpenFilm projekat (1080×1920, 30 s). `film.html` je montaža, `s1`–`s7` su scene, `lib/` je zlatno-plavi brand kit.

- Pregled: `npx -y openfilm@latest look --count 24`
- Render: `npx -y openfilm@latest render --fps 30` pa `tools/export_instagram.sh literatura-reel.mp4 seminarskiedu-literatura-instagram.mp4`
- Muzika i SFX: `python3 tools/make_audio.py assets`

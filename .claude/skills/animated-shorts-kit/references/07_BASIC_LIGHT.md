# Basic light (simple rules — the premium light layer is a separate kit)
- One key light (the sun) from the front-side, ~40° up; keep its direction the same in every shot.
- Warm key, cool fill: warm white sun + soft blue sky fill → shadows read slightly blue.
- Medium brightness overall; never crush blacks; faces stay white and readable.
- The main story object gets the most light and the most detail.
- Indoors: same rule, softer key through the windows + a little ambient.
Code: `code/src/engine/look/look.ts` (flat toon ramp + one light rig + plain sky).
